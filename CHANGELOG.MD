# Changelog

## heckler-v1

**T10:** Scoped setuptools package discovery in `pyproject.toml` (`[tool.setuptools.packages.find]` / `include = ["heckler*"]`) so `pip install -e .` does not treat `prompts/`, `tests/`, and other sibling dirs as top-level packages. Widened `Reactor.react()` to `tuple[Optional[ReactorResult], float, Optional[DiscardReason]]` (third element `None` on success, `LLM_ERROR` on API/parse failure, `SCORE_GATE` below threshold); removed `_install_reactor_discard_tracking` / `_react_with_discard` and the pipeline import of `_extract_text_content`, so the reaction worker reads discard semantics from `react()` directly. Updated `tests/test_reactor.py` and `tests/test_pipeline.py` (including `_run_reaction_worker` coverage for direct `reactor.react` calls and pacing rejection after a successful react).

**T9:** Added `heckler/pipeline.py` (`main`, threaded capture → transcribe → semantic gate → reaction queue with drop-oldest overflow matching `audio_capture`, reaction worker with `pacing_gate.record_output()` strictly before `speaker.speak()`, `_react_with_discard` wrapper for §2 `LLM_ERROR` vs `SCORE_GATE`, graceful shutdown via sentinels + joins), `heckler/__main__.py` for `python -m heckler`, argparse `--list-devices`, stdout startup banners with timings, `README.md` (CUDA torch install, `.env` vars from `.env.example`, usage, first-run downloads), and `tests/test_pipeline.py`. **Decision log:** `.dev/decision-logs/T9.md`. **Deferred:** full threaded shutdown fuzz under artificial queue floods — covered indirectly via `_put_shutdown_sentinel` unit test; expand if CI gains deterministic stress hooks.

**T8:** Implemented `heckler/speaker.py` — Kokoro `KPipeline(lang_code="a")` with `logger.info("downloading TTS model")` before construction, `Speaker.is_playing` mic gate (`set` before synthesis, `clear` after playback via `finally` or on synthesis/`_collect_audio` failure), `sounddevice.play(..., samplerate=24000, blocking=True)`, tuple-shaped Kokoro chunks validated in `_collect_audio`, and `SpeakerError` wrapping synthesis failures. Tests in `tests/test_speaker.py`. **Deferred:** unit assertion that `speak()` return value equals synthesis-only wall time (not playback) — low risk given `perf_counter` boundaries in code; add if latency metrics become contract-tested.

**T2:** Added `heckler/semantic_gate.py` with seed-aligned `STOPWORDS`, `compute_density()`, and `passes_gate()` (lexical density plus `min_word_count` / `density_threshold` from `HecklerConfig`); phrase `you know` is removed with `\byou\s+know\b` before tokenization (per packet risk). Tests in `tests/test_semantic_gate.py`.

**T5:** Implemented `heckler/transcriber.py` (`Transcriber`) around faster-whisper with mandatory `vad_filter=True` and `condition_on_previous_text=False`, startup `[HECKLER]` load logs, and `run()` that emits stripped transcripts including empty strings for silence artifacts. Tests in `tests/test_transcriber.py` mock `WhisperModel` so CI stays GPU-free. **Deferred:** malformed `in_queue` items not asserted — wire contract assumes valid `AudioChunk` inputs from capture.

**T6:** Added `PacingGate` with `evaluate` / `record_output()` (thread-safe lock, cooldown via `min_output_interval_s`, high-score bypass when `score >= score_override_threshold`). Docstrings document calling `record_output()` immediately before TTS (`speaker.speak()`), per T9 coupling surface. Tests in `tests/test_pacing_gate.py` use monkeypatched `time.time`, concurrent `evaluate`, interleaved stress, and an elapsed-equals-interval boundary falsifier.

**T3:** Added `ContextBuffer` (thread-safe rolling transcript window) and `HecklerLogger` (append-only daily JSONL, `HeckleEvent` serialization with enum coercion and defensive `audio_chunk` stripping, path recomputed per event for calendar rollover). Tests in `tests/test_context_buffer_and_logger.py`. **Deferred:** asserting failure behavior when the log path is not writable (permissions / disk full) — integration concern once pipeline wiring exists.

**T4:** Added `heckler/audio_capture.py` with `AudioCapture(config, out_queue, is_playing)` — Silero VAD via `torch.hub.load` and streaming `VADIterator`, 512-sample / 16 kHz frames (current Silero requirement; the seed’s 480-sample note is superseded by upstream), `sounddevice` callback feeding a bounded deque drained in `_capture_loop`, `is_playing` gate before enqueue, drop-oldest on queue overflow, and max-speech force flush with a fresh iterator. **`tests/test_audio_capture.py`** covers overflow policy, sample-rate guard, emit gating, and dtype validation. **Packet note:** T4 listed only `audio_capture.py`; tests and this changelog line follow the executor test mandate and repo `tests/test_<module>.py` convention.

**T1:** Introduced the heckler package with shared models (JSON serialization with enum values and defensive `audio_chunk` stripping), frozen `HecklerConfig` and `load_dotenv`-aware `load_config()`, seed-aligned `pyproject.toml` and `.env.example`, plus `tests/test_models.py`. **Deferred:** explicit tests for invalid enum strings in `heckle_event_from_json_dict` (`ValueError`) — reserved for reactor/logger integration behavior in later tasks.

**T7:** Added `heckler/reactor.py` (`Reactor`, `_parse_response` with JSON + regex fallback `r'\{[^}]+\}'`, synchronous non-streaming Anthropic calls, score gate `score < score_threshold`), verbatim `prompts/system.md` and `prompts/examples.json`, and `tests/test_reactor.py` with mocked client behavior. **Decision log:** `.dev/decision-logs/T7.md`.
