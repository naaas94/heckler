Plan: decompose persisted `events.payload_json` into relational structure for post hoc SQL analytics while preserving `HeckleEvent` JSON contracts and the legacy JSONL import path. Full decomposition: `.dev/plans/sqlite-event-decomposition-analytics/plan.md`.

- **T1 (Architecture decision freeze):** Landed owner resolutions for context-map Flags 1–6 in `.dev/decision-logs/T20-event-decomposition-arch.md` — normalized SSOT for analytics with `serialize_heckle_event` / `heckle_event_from_json_dict` still defining field semantics; automatic `init_schema`-path migration with pytest fixture coverage; eval-adjacent tables in the same DB file; dual “eval” vocabulary with doc disambiguation owned by T5; **required** pytest for import/dedupe/insert paths touched by decomposition; `reactor_result` in child table **`event_reactor_results`** (FK `event_id`); dataset-eval table name **`heckler_eval_labels`**. **Rationale:** Removes executor guesswork on SSOT, migration, and test policy before T2–T5 land DDL and writers. **Decision log:** `.dev/decision-logs/T20-event-decomposition-arch.md`. **+** `tests/test_t20_event_decomposition_architecture_log.py` (flags 1–6 **Landed** presence guard).

- **T4 (Legacy JSONL import dedupe + insert parity):** **`scripts/import_legacy_jsonl.py`** now dedupes **`--skip-existing`** with **`COALESCE(utterance_id, json_extract(payload_json, '$.utterance_id'))`** (same **`$.timestamp_iso`** path) so skips match v2 normalized rows and legacy JSON-only rows, and inserts use the same normalized **`events`** columns plus **`event_reactor_results`** as **`insert_heckle_event_row`**, still under one commit per **`import_lines`** batch. **Rationale:** Aligns import with T21 SSOT and logger shape (T20 Flag 5). **`+`** **`tests/test_import_legacy_jsonl.py`**. **Deferred:** falsifier for SQLite builds **without** JSON1 **`OperationalError`** branch would need a custom build; error message path remains manual.

- **T5 (Docs + retired-string sweep):** **`heckler/pipeline.py`** module docstring now describes SQLite persistence instead of JSONL logging; **`README.md`** adds legacy-import CLI (`python scripts/import_legacy_jsonl.py` with **`--database`** / **`-d`**, **`--dry-run`**, **`--skip-existing`**) and disambiguates pacing **`cooldown_remaining_at_eval`** from dataset-style **`heckler_eval_labels`** (T20 Flag 4). **`.dev/plans/sqlite-event-decomposition-analytics/context-map.md`** and **`plan.md`** (hidden couplings) plus **`packets/T4.md`** coupling note updated so **`SCHEMA_VERSION`** and import/insert paths match post-T2 code (**`insert_heckle_event_row`**, schema v2). **Deferred:** no pytest asserts README or module docstring prose—doc-only slice; falsifier would need a dedicated doc contract test outside this packet’s primary touch list.

- **T3 (Logger write path + transactional denormalized insert):** Added **`insert_heckle_event_row`** in **`heckler/event_store.py`** so live logging writes **`payload_json`** (still built from **`serialize_heckle_event`**) **and** v2 normalized **`events`** columns plus **`event_reactor_results`** when present, all in **one commit**. **`HecklerLogger.log_event`** now calls that helper under the existing lock. **Rationale:** Matches T21/T20 physical SSOT for analytics without partial parent/child writes on failure. **Deferred:** child-insert fault injection to assert rollback clears the parent row (see adversarial note in **`tests/test_context_buffer_and_logger.py`**).

## sqlite-local-db-obs-langfuse

Plan: replace append-only JSONL under `**log_dir**` with **SQLite** as the sole steady-state event store (stdlib `**sqlite3`**), add reactor-local **LiteLLM** tracing hooks and correlation into persisted rows, and keep scope minimal (no eval UI, no audio in DB). Full decomposition and auditor handoff (plan **v1.1.0**, §8): `.dev/plans/sqlite-local-db-obs-langfuse/plan.md`.

**T1:** Added `**heckler/event_store.py`** (`**open_store`**, `**init_schema**`, `**insert_event_row**`, `**events**` + `**heckler_schema_version**` DDL, WAL / busy-timeout pragmas for single-process multi-threaded use) and `**heckler/tracing_context.py**` (thread-local `**str` → `str**` correlation for reaction-thread LiteLLM metadata). Tests in `**tests/test_event_store.py**`. **Decision log:** `.dev/decision-logs/T12.md`.

**T2:** Retired `**HecklerConfig.log_dir`**; added `**sqlite_database_path`** (default `**logs/heckler.db**`) and `**load_config()**` parsing of `**HECKLER_DATABASE_PATH**` — value is stripped and overrides the default only when non-empty after strip (whitespace-only env falls back to default; `**test_load_config_without_llm_keys**` clears `**HECKLER_DATABASE_PATH**` assert default path). `**heckler/logger.py**` uses `**Path(sqlite_database_path).parent**` for `**mkdir(parents=True)**`; internal naming moved off `**log_dir**`. Steady-state event persistence is SQLite-only after **T3** (no interim JSONL). `**tests/test_models.py**`: defaults, `**HECKLER_DATABASE_PATH**` override in `**test_load_config_env_overrides**`, whitespace falsifier `**test_load_config_heckler_database_path_whitespace_falls_back_to_default**`. `**tests/test_context_buffer_and_logger.py**`: `**HecklerConfig(sqlite_database_path=...)**` instead of `**log_dir**`, `**test_logger_creates_parent_directory_for_sqlite_path**` (replaces `**test_logger_log_dir_created**`). No edits needed for `**tests/test_audio_capture.py**` / `**tests/test_pipeline.py**` (**no `log_dir` references**). No new dependencies. **Decision log:** `.dev/decision-logs/T13.md`.

**T3:** `**HecklerLogger`** is SQLite-only for steady-state events: opens the DB at `**config.sqlite_database_path`**, initializes schema once, and inserts under the existing `**threading.Lock**` so the shared `**sqlite3**` connection ( `**check_same_thread=False**`, per **T12**) avoids writer contention. Payload uses `**serialize_heckle_event`** + `**json.dumps`** only (removed `**_serialize` / `_coerce_json**`, daily `**heckler_*.jsonl**` paths, and `**_path_for_date**`). Optional `**tracing_context**` is written to `**correlation_json**` and `**clear_correlation()**` runs in `**finally**` so metadata does not leak across `**log_event**` calls; insert failures log at **ERROR** and re-raise. **Rationale:** one JSON shape contract with `**heckler/models.py`**, correlation lifecycle localized to the logging path, and write failures remain visible to callers. Tests rewritten in `**tests/test_context_buffer_and_logger.py`** (including failure-path and correlation-clearing falsifiers). Deferred: explicit `**Connection.close()**` on pipeline shutdown (see **T14**). **Decision log:** `.dev/decision-logs/T14.md`.

**T4:** `**Reactor.react`** clears `**tracing_context`** before each `**litellm.completion**` and again on completion exceptions; after a successful return, correlation uses only primitive values from the response (`**id**` → `**completion_id**`, `**model**`, `**system_fingerprint**`, and `**_hidden_params**` `**litellm_call_id**` / `**model_id**` when dict-backed) so placeholder mocks do not leak into `**correlation_json**`. Hosted-observability scaffold: when env indicates Langfuse (`**LANGFUSE_PUBLIC_KEY**` + `**LANGFUSE_SECRET_KEY**`) or LangSmith-style tracing (`**LANGCHAIN_TRACING_V2**` / `**LANGSMITH_TRACING**` with `**LANGCHAIN_API_KEY**` / `**LANGSMITH_API_KEY**`), `**litellm.completion**` receives `**metadata**` (`**generation_name**`: `**heckler.react**`, tags `**heckler**` / `**heckler-reactor**`) without mutating global LiteLLM callback lists (single instrumentation surface; avoids duplicate trace roots). **Rationale:** LiteLLM ≥1.40 forwards `**metadata`** to logging/callback integrations operators enable separately; heckler adds reaction-thread correlation for SQLite joins. LLM failures remain `**(None, latency_ms, DiscardReason.LLM_ERROR)**` with provider-agnostic error logging. **Tests:** `**tests/test_reactor.py`** — `**metadata**` present/absent by env, correlation fields from explicit response attrs, MagicMock attr falsifier, stale correlation cleared on API exception. No new dependencies. **Decision log:** `.dev/decision-logs/T15.md`.

**T5:** Closed documentation and tests deferred from **T2**: **README** now describes SQLite (`**logs/heckler.db**` default) as the sole steady-state event sink, documents **`HECKLER_DATABASE_PATH`** and retired **`log_dir`** / daily **`heckler_*.jsonl`** paths (historical only), replaces the old “append to JSONL” usage line with SQLite + stdout banners, adds **`LOG_DENSITY_FAILURES`** semantics (density rejects go through the same SQLite **`HeckleEvent`** path when enabled), and adds an informational observability table (`**LANGFUSE_PUBLIC_KEY**` / `**LANGFUSE_SECRET_KEY**`; `**LANGCHAIN_TRACING_V2**` or `**LANGSMITH_TRACING**` with `**LANGCHAIN_API_KEY**` or `**LANGSMITH_API_KEY**`). **`.env.example`** gains commented **`HECKLER_DATABASE_PATH`** and the same tracing vars (optional; no-op when unset). Corrected the sqlite-plan **T2** bullet in this changelog that still claimed interim JSONL post-**T3**. **`tests/test_models.py`**: added **`test_config_has_sqlite_path_not_log_dir`** (regression guard on **`HecklerConfig`** fields). No further **`log_dir`** / JSONL test drift found; full pytest green (**113** tests).

**T6:** Added **`scripts/import_legacy_jsonl.py`** — one-shot import of legacy **`heckler_YYYY-MM-DD.jsonl`** lines into **`events`** using **`heckle_event_from_json_dict`** validation and the same payload path as live logging (**`serialize_heckle_event`** + **`json.dumps`** + **`insert_event_row`** with **`correlation_json=NULL`**). **`--skip-existing`** dedupes by **`(utterance_id, timestamp_iso)`** via **`json_extract`** on **`payload_json`**; **`--dry-run`** validates without writes; reads JSONL as **`utf-8-sig`** so a UTF-8 BOM does not break **`json.loads`**. ## litellm-provider-switch

Full decomposition and contracts: `.dev/plans/litellm-provider-switch/plan.md`.

**T4:** Updated `**.env.example`** and `**README.md`** for LiteLLM multi-provider setup, default `**openai/gpt-4o-mini**`, and env keys aligned with `**load_config()**` (`HECKLER_LLM_MODEL`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `OLLAMA_API_BASE`, plus existing Whisper/Kokoro/pacing vars).
