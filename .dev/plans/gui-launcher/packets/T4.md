# Executor Packet — T4: Documentation

---

## §1 Task statement

Build a minimal PyQt6 GUI launcher for Heckler that replaces the blocking CLI `main()` loop with a Qt event loop, exposes persona hot-swap (runtime `Reactor` replacement between utterances) and mode switching (persona ↔ transcribe) in a single window with live transcript/reaction feeds and session controls. The GUI layer is the integration surface deferred by both the persona-system and transcription-engine plans.

**Non-goals:**

- Advanced GUI features (settings panels for VAD thresholds, LLM temperature sliders, session history browser, tray icon).
- Multi-window or multi-monitor support.
- Electron, web, or any non-PyQt6 frontend.
- Changes to the LLM, TTS, or transcription backends (Reactor, Speaker, Transcriber internals unchanged).
- Mobile or cross-platform packaging.
- CLI flag changes on the existing `heckler` entry point.

## Implementation guidance

Add a new `## GUI` section to `README.md` after the existing `## Usage` section. Content should cover:

### Section: GUI

```markdown
## GUI

Launch the graphical interface:

```bash
heckler-gui
```

The GUI provides:

- **Mode toggle** — switch between persona and transcribe modes at runtime without restarting.
- **Persona picker** — select and hot-swap persona bundles while the pipeline is running.
- **Live feed** — real-time transcript of what is being said, plus AI reactions in persona mode.
- **Session controls** — start/stop transcription sessions and export to markdown (transcribe mode).

Model loading (Whisper + Kokoro TTS) happens once at startup with a progress indicator (~13 seconds on first launch with CUDA).

The `heckler` CLI continues to work as before for headless / terminal-only usage.
```

**Key constraints:**
- Use `heckler-gui` exactly — not `heckler --gui` or `heckler_gui`.
- Do not duplicate the configuration table (PyQt6 has no user-facing config variables in v1).
- Keep the section brief. This is a launcher, not a full application manual.
