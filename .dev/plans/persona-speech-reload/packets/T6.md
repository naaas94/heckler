# Executor Packet — T6: CLI `ensure_heavy_models` before start

## §1. Task statement (verbatim)

Heckler's CLI (`pipeline.main()`) calls `load_models` then `start` but does not call `ensure_heavy_models` to guarantee the loaded speech stack matches the selected persona's locale before starting. This subtask adds that call, ensuring S12 (`--persona heckler_arg` → es at load) works correctly from the CLI.

**Non-goals (v1):** No new CLI flags; no interactive hot-swap from CLI; `auto` policy only (no ask dialog in CLI — D16).

---

## §2. Shared contracts (verbatim)

### Sentinel rule
`locale_override = None` → "From persona / use config default". No new CLI locale override flag in v1.

### Types / interfaces (T6 rows)
- `PipelineController.ensure_heavy_models(*, persona_name, locale_override, on_progress, mode) -> bool` — consumed (produced by T2).

### CLI surface (binding — no change)
No new flags. Existing `--persona` and `--mode` flags unchanged.

### Design decision (T6): single `ensure_heavy_models` call
Replace the explicit `load_models(...)` call in `pipeline.main()` with a single `controller.ensure_heavy_models(...)` call. Rationale: `ensure_heavy_models` calls `load_models` internally when needed (always needed on startup since `loaded_speech_stack()` is `None`). Eliminates the double-load risk (explicit `load_models` + `ensure_heavy_models` would load twice).

**Kill criterion corollary:** If both `load_models` and `ensure_heavy_models` are called on startup path — halt; double-load.

### Tests
- Framework: `pytest`; location: `tests/test_pipeline.py`
- `test_cli_persona_heckler_arg_calls_ensure_heavy_models` — mock controller; verify `ensure_heavy_models` called with `persona_name="heckler_arg"`
- `test_cli_transcribe_mode_ensure_heavy_models_no_speaker` — mode="transcribe" passes mode to ensure
- `test_cli_no_double_load` — verify `load_models` not called directly when `ensure_heavy_models` present

### Verification command
```bash
pytest tests/test_pipeline.py -q
```

## §4. Subtask spec

**Scope:** Update `pipeline.main()` to call `controller.ensure_heavy_models(...)` as the single model-loading call (replacing the explicit `controller.load_models(...)` call). Document voice-only-change / same-locale = no reload in inline comment.

**Files to touch:**
- `heckler/pipeline.py`
- `tests/test_pipeline.py`

**Contract bindings:** §2 CLI surface (no new flags). §2 Types: `ensure_heavy_models` signature. §2 Tests.

**Inputs:**
- T2 output: `PipelineController.ensure_heavy_models` available in `heckler.controller`.

**Outputs:**
1. `heckler/pipeline.py` — `ensure_heavy_models` replaces `load_models` in `main()`.
2. `tests/test_pipeline.py` — three new tests above.

**Kill criteria:**
1. If both `controller.load_models(...)` and `controller.ensure_heavy_models(...)` are called in `main()` — halt; double-load (see design decision above).
2. If `ensure_heavy_models` is called after `controller.start(...)` — halt; must precede start.
3. If new CLI flags are introduced — halt; non-goal.
4. If `mode="transcribe"` path accidentally passes `persona_name` to `ensure_heavy_models` — halt; transcribe mode has no persona.
5. If the existing exception handling block (currently `except Exception as exc:` around `load_models`) is dropped without replacement — halt; CLI must still exit cleanly on model load failure.

**Log tier:** `standard`

**Risks & mitigations:**
- Current `pipeline.main()` calls:
  ```python
  controller.load_models(
      on_progress=lambda msg: print(f"[HECKLER] {msg}", flush=True),
      mode=mode,
      persona_name=persona_name if mode == "persona" else None,
  )
  ```
  Replace with:
  ```python
  controller.ensure_heavy_models(
      persona_name=persona_name if mode == "persona" else None,
      locale_override=None,  # No CLI locale override in v1
      on_progress=lambda msg: print(f"[HECKLER] {msg}", flush=True),
      mode=mode,
  )
  ```
  Keep the existing `try/except Exception` wrapper; just replace the inner call.
- `ensure_heavy_models` returns `bool` (True = reloaded, False = no-op). CLI does not need to inspect the return value; ignore it.
