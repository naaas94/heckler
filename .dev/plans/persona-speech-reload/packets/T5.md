## §1. Task statement (verbatim)

Heckler's GUI fails to handle cross-locale persona hot-swap correctly: it calls `swap_persona` regardless of speech-stack signature change, leaving STT/TTS in the wrong language. This subtask delivers the GUI-side unified orchestration (`_apply_persona_and_speech`), the ask dialog (while running), the `_reloading` mutex, voice/locale mismatch warning (G5), failure revert (G9), and the "Reload speech models" button (D8).

**Non-goals (v1):** QSettings "don't ask again"; persisting locale override; in-place model swap; GUI theme changes.

### `_reloading` mutex (binding)
- `self._reloading: bool = False` initialized in `__init__`
- Set `True` at the start of any reload operation; set `False` in all exit paths (success, cancel, exception)
- While `True`: Start, persona combo, locale combo, mode radios, Reload button all disabled

### Cancel behavior (D13, binding)
On ask dialog cancel: revert persona combo AND locale combo to pre-change values; do NOT call `swap_persona` or `reload_speech_stack_for_persona`; status bar: `"Reload cancelled — still using <prev language> speech"`.

### Reload ordering (§18.1, binding)
Compute `heavy_models_need_reload` BEFORE any Reactor swap. If reload needed, apply policy FIRST. Reactor swap only happens on the same-signature path (no dialog, no reload).

### Ask dialog copy (§6.3, binding)
- Title: `"Reload speech models?"`
- Body: `"Switching speech to <Language> requires reloading Whisper and Kokoro (~20–60 s). The mic will stop briefly.\nContinue?"`
- Buttons: `"Reload"` (default, `QMessageBox.StandardButton.Ok`) · `"Cancel"` (`QMessageBox.StandardButton.Cancel`)

### Voice/locale prefix heuristic (G5, D9 non-blocking)
If `kokoro_voice` prefix (`af_`, `am_`, `bf_`, `bm_`, `ef_`, `em_`) is incompatible with resolved `kokoro_lang_code`:
- `a` (American English): expects `af_*` or `am_*`
- `b` (British English): expects `bf_*` or `bm_*`
- `e` (Spanish): expects `ef_*` or `em_*`
Show non-blocking WARNING log + status bar message. Do NOT block reload. Message: `"Warning: <voice> is an English voice; use ef_dora for Spanish"` (or equivalent).

**Kill criteria:**
1. If cancel path calls `swap_persona` or `reload_speech_stack_for_persona` before the user confirms — halt; reload-before-Reactor ordering violated.
2. If cancel does NOT revert both persona combo and locale combo — halt; D13 violated.
3. If `_reloading` is not set to `False` in the exception handler — halt; mutex leak (G8).
4. If voice/locale heuristic calls `resolve_locale(voice_name)` — halt; voice name is not a locale slug.
5. If `_reload_speech_btn` is not disabled when `_reloading == True` — halt; G13 violated.
6. If ask dialog is shown when `running == False` — halt; D6 says no dialog before Start.
7. If `_on_start_stop` does not check `_reloading` at entry and guard against double-Start — halt; D10 violated.
8. If `reload_speech_stack_for_persona` is called synchronously on the GUI thread without offloading — halt; window freezes for 30–60 s (see §5.2 assumption 4).

**Log tier:** `standard`

**Risks & mitigations:**
- **GUI thread blocking (critical):** `reload_speech_stack_for_persona` calls `stop()` + `load_models()` + `start()`, blocking for 30–60 s. Must be run in a `QThread`. Use the same `QThread` pattern as `ModelLoadThread`: create a subclass (e.g. `ReloadThread`) that calls `reload_speech_stack_for_persona`, emits `finished_ok` / `failed(str)` signals. Set `_reloading = True` before starting thread, `False` in both signal handlers.
- **Combo revert on cancel:** save current combo indices BEFORE showing dialog; restore on cancel.
- **`_on_persona_changed` running path:** T3 left the `swap_persona` call in the running path unchanged. T5 replaces it with `_apply_persona_and_speech(name, locale_override, running=True, reload_policy=SpeechReloadPolicy.ask, on_progress=...)`.

## Implementation guidance

### `_apply_persona_and_speech` skeleton

```python
def _apply_persona_and_speech(
    self,
    persona_name: str,
    locale_override: "str | None",
    *,
    running: bool,
    reload_policy: "SpeechReloadPolicy",
    on_progress: "Callable[[str], None]",
) -> None:
    from heckler.controller import SpeechReloadPolicy

    needs_reload = self._controller.heavy_models_need_reload(
        persona_name=persona_name, locale_override=locale_override
    )
    self._check_voice_locale_warning(persona_name, locale_override)

    if not needs_reload:
        # Same-sig: hot-swap Reactor only
        logger.info("Same-locale swap to %r (no reload)", persona_name)
        try:
            self._controller.swap_persona(persona_name)
        except Exception as e:
            self._show_error(str(e))
        return

    # Cross-locale path — reload required
    if reload_policy == SpeechReloadPolicy.never:
        logger.warning("Reload needed but policy=never; skipping")
        return

    if running and reload_policy == SpeechReloadPolicy.ask:
        # Show ask dialog
        prev_persona_idx = self._persona_combo.currentIndex()
        prev_locale_idx = self._locale_combo.currentIndex()

        from PyQt6.QtWidgets import QMessageBox
        # Determine target language for dialog body
        target_cfg = self._controller.target_speech_config(
            persona_name=persona_name, locale_override=locale_override
        )
        lang = target_cfg.locale.upper()
        reply = QMessageBox.question(
            self,
            "Reload speech models?",
            f"Switching speech to {lang} requires reloading Whisper and Kokoro (~20–60 s)."
            f" The mic will stop briefly.\nContinue?",
            QMessageBox.StandardButton.Ok | QMessageBox.StandardButton.Cancel,
            QMessageBox.StandardButton.Ok,
        )
        if reply != QMessageBox.StandardButton.Ok:
            # Cancel: revert combos
            self._persona_combo.blockSignals(True)
            self._persona_combo.setCurrentIndex(prev_persona_idx)
            self._persona_combo.blockSignals(False)
            self._locale_combo.blockSignals(True)
            self._locale_combo.setCurrentIndex(prev_locale_idx)
            self._locale_combo.blockSignals(False)
            sb = self.statusBar()
            if sb:
                sb.showMessage(f"Reload cancelled — still using previous speech")
            return

    # Proceed with reload (auto or confirmed ask)
    self._start_reload(persona_name=persona_name, locale_override=locale_override,
                       on_progress=on_progress)


def _start_reload(
    self,
    *,
    persona_name: "str | None",
    locale_override: "str | None",
    on_progress: "Callable[[str], None]",
) -> None:
    self._reloading = True
    self._apply_models_ready(self._models_ready)  # disable controls

    # Use QThread to avoid blocking GUI
    self._reload_thread = _ReloadThread(
        self._controller, persona_name=persona_name, locale_override=locale_override
    )
    self._reload_thread.progress.connect(lambda m: self.statusBar().showMessage(m))
    self._reload_thread.finished_ok.connect(lambda: self._on_reload_done(True, None))
    self._reload_thread.failed.connect(lambda msg: self._on_reload_done(False, msg))
    self._reload_thread.start()


def _on_reload_done(self, success: bool, error_msg: "str | None") -> None:
    self._reloading = False
    self._apply_models_ready(self._models_ready)
    if success:
        self.statusBar().showMessage("Speech models reloaded.")
    else:
        self._show_error(f"Reload failed: {error_msg}")
```

### `_ReloadThread` (inner class or module-level)

```python
class _ReloadThread(QThread):
    progress = pyqtSignal(str)
    finished_ok = pyqtSignal()
    failed = pyqtSignal(str)

    def __init__(self, controller, *, persona_name, locale_override):
        super().__init__()
        self._controller = controller
        self._persona_name = persona_name
        self._locale_override = locale_override

    def run(self) -> None:
        try:
            self._controller.reload_speech_stack_for_persona(
                persona_name=self._persona_name,
                locale_override=self._locale_override,
                on_progress=self.progress.emit,
            )
            self.finished_ok.emit()
        except Exception as e:
            self.failed.emit(str(e))
```

At the top of the persona start branch:

```python
# ...
from heckler.controller import SpeechReloadPolicy
def _on_prog(msg: str) -> None:
    sb = self.statusBar()
    if sb:
        sb.showMessage(msg)
self._apply_persona_and_speech(
    persona or "",
    self.selected_locale_override(),
    running=False,  # Start path: no ask dialog
    reload_policy=SpeechReloadPolicy.auto,
    on_progress=_on_prog,

# start() is called inside _apply_persona_and_speech (via reload path) or must be called after
```

**Important:** For the Start button (not-running), the reload path calls `reload_speech_stack_for_persona` which does `stop() + load_models() + start()`. But if not running, `stop()` is a no-op and `start()` is called after load. The `controller.start()` call in `_on_start_stop` may conflict. Design decision: for the not-running path, `_apply_persona_and_speech` handles the full lifecycle (ensure + start). Executor should verify that `controller.start()` is called exactly once (not double-started by both `_apply_persona_and_speech` and `_on_start_stop`). The simplest pattern: after `_apply_persona_and_speech` returns (non-reload path), call `controller.start()`; for the reload path, `reload_speech_stack_for_persona` calls `start()` internally.
