## §1. Task statement (verbatim)

Heckler's GUI and CLI fail to propagate locale into the Whisper and Kokoro heavy models when the operator selects a persona with a non-English locale. This plan delivers a GUI locale override combo, a unified `_apply_persona_and_speech` orchestration entry point, a reload policy (auto on Start, ask while running), and CLI parity.

**Non-goals (v1):** Speaker-only reload on voice-only change; persisting locale override to disk; LLM locale injection; locale in Transcribe mode; new locales beyond `en/en-us/en-gb/es`; in-place model swap; GUI theme changes; QSettings "don't ask again".

**Kill criteria:**

2. If locale combo is populated by hardcoded list of slugs rather than `supported_locale_labels()` — halt; duplication risk.

**Log tier:** `standard`

- Layout placement: add a `QLabel("Speech:")` + `_locale_combo` row after the existing persona row. Use the existing `header` `QHBoxLayout` pattern or a new one.

## Implementation guidance

### Widget layout (add after persona row)

```python
speech_row = QHBoxLayout()
speech_row.addWidget(QLabel("Speech:"))
self._locale_combo = QComboBox()
speech_row.addWidget(self._locale_combo, stretch=1)
root.addLayout(speech_row)
```

### `_populate_locale_combo`

```python
def _populate_locale_combo(self) -> None:
    from heckler.locale import supported_locale_labels
    self._locale_combo.blockSignals(True)
    self._locale_combo.clear()
    self._locale_combo.addItem("From persona")
    for slug in supported_locale_labels():
        self._locale_combo.addItem(slug)
    self._locale_combo.setCurrentIndex(0)
    self._locale_combo.blockSignals(False)
```

Call `_populate_locale_combo()` in `__init__` after `_populate_personas()`.

### `selected_locale_override`

```python
def selected_locale_override(self) -> str | None:
    text = self._locale_combo.currentText()
    if text == "From persona" or not text:
        return None
    return text
```

### Locale sync in `_on_persona_changed` (not-running path)

```python
def _on_persona_changed(self, _name: str) -> None:
    name = self._persona_combo.currentText()
    if not name:
        return
    # Not-running: sync locale combo from persona TOML
    if not self._controller.is_running or self._controller.current_mode != "persona":
        try:
            from heckler.persona import load_persona
            persona = load_persona(_prompts_root() / name)
            # persona.toml [voice].locale → find in combo or reset to "From persona"
            locale = getattr(persona.config, "locale", None)
            if locale:
                idx = self._locale_combo.findText(locale)
                self._locale_combo.blockSignals(True)
                self._locale_combo.setCurrentIndex(idx if idx >= 0 else 0)
                self._locale_combo.blockSignals(False)
            else:
                self._locale_combo.blockSignals(True)
                self._locale_combo.setCurrentIndex(0)
                self._locale_combo.blockSignals(False)
        except Exception:
            logger.debug("Could not sync locale combo from persona %r", name)
        return
    # Running path: unchanged for T3; T5 will replace this block
    try:
        self._controller.swap_persona(name)
    except (PipelineNotRunningError, PersonaNotFoundError) as e:
        self._show_error(str(e))
```

### `_apply_models_ready` update

Add to the existing method:

persona_mode = self._selected_mode() == "persona"
