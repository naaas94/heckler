## §1. Task statement (verbatim)

Heckler's GUI and CLI fail to propagate locale into the Whisper and Kokoro heavy models when the operator selects a persona with a non-English locale. Specifically: F1 — `ModelLoadThread` reads `config.persona_name` at init instead of the live combo at thread start; F2 — the persona combo is disabled until the pipeline is running, blocking pre-Start selection. This plan fixes both.

**Non-goals (v1):** Speaker-only reload on voice-only change; persisting locale override; LLM locale injection; locale in Transcribe mode; new locales; in-place model swap; GUI theme changes; QSettings "don't ask again".

## Implementation guidance

### `ModelLoadThread` refactored (`app.py`)

```python
from typing import Callable

class ModelLoadThread(QThread):
    progress = pyqtSignal(str)
    finished_ok = pyqtSignal()
    failed = pyqtSignal(str)

    def __init__(
        self,
        controller: PipelineController,
        mode: str,
        persona_name_fn: Callable[[], str],
        locale_override_fn: Callable[[], "str | None"],
    ) -> None:
        super().__init__()
        self._controller = controller
        self._mode = mode
        self._persona_name_fn = persona_name_fn
        self._locale_override_fn = locale_override_fn

    def run(self) -> None:  # pragma: no cover
        threading.current_thread().name = "heckler-gui-loader"
        try:
            def on_prog(msg: str) -> None:
                self.progress.emit(msg)

            persona_name = self._persona_name_fn() if self._mode == "persona" else None
            locale_override = self._locale_override_fn()
            self._controller.load_models(
                on_progress=on_prog,
                mode=self._mode,
                persona_name=persona_name,
                locale_override=locale_override,
            )
            self.finished_ok.emit()
        except Exception as e:
            logger.exception("Model loading failed")
            self.failed.emit(str(e))
```
