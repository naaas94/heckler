# T11 — LiteLLM reactor integration

## Chosen approach

- **`litellm.completion`** is invoked from **`Reactor.react`** with **`model=config.llm_model`**, OpenAI-style **`messages`**: system message from `prompts/system.md`, user message containing the prior examples block, context, utterance, and JSON-only instruction (same content split as the former Anthropic path).
- **Credentials:** **`api_key`** is passed only when non-empty for the provider inferred from the LiteLLM model id prefix (**`openai/`** and **`azure/`** → **`openai_api_key`**, **`anthropic/`** → **`anthropic_api_key`**). **`api_base`** is passed for **`ollama/`** when **`ollama_api_base`** is non-empty. Missing prefix (bare model id) uses **`openai_api_key`** when set. Otherwise kwargs are omitted so LiteLLM / process environment defaults apply.
- **Assistant text** is read via the package-level **`heckler.reactor.completion_assistant_text`**, which expects an OpenAI-compatible response with **`choices[0].message.content`** (`str` or list parts). **`Reactor.react`** uses this function so T3 can regression-test extraction without private helpers.

## Alternatives rejected

- **Keep Anthropic SDK alongside LiteLLM:** Rejected—§2 requires a single LiteLLM entrypoint and dropping the **`anthropic`** runtime dependency once **`heckler/reactor.py`** no longer imports it.
- **Import `litellm` at module import time:** Rejected for this pass in favor of importing inside **`react`** to limit import-time side effects in test and offline contexts (per context-map coupling note).

## Assumptions made

- LiteLLM accepts the same **`max_tokens`** / **`temperature`** kwargs for the configured **`model`** strings operators use in v1 (including **`openai/gpt-4o-mini`**).
- Provider routing by **`model`** prefix matches operator expectations for **`openai/`**, **`azure/`**, **`anthropic/`**, and **`ollama/`**; other prefixes rely on empty-config omission and LiteLLM/env behavior.

## Items deferred

- **Broader provider-specific kwargs** (custom Azure endpoints beyond shared **`api_key`**, Vertex, etc.): deferred until a contract names additional **`HecklerConfig`** fields.
- **Richer extraction tests** for **`completion_assistant_text`** (multimodal list parts, edge shapes): owned by **T3** per packet Flag 3.
