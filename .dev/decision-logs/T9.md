# Decision log — T9 (Pipeline + README)

## How to read this log

**Current behavior** matches **`heckler/pipeline.py`** and the reactor seam documented in **T7**. **Historical** sections archive superseded planning text only.

## Current behavior (shipped)

- **`main`** (`heckler.pipeline:main`): **`load_config()`** → **`HecklerLogger`** → **`Transcriber`** → **`Speaker`** → **`Reactor`** → **`ContextBuffer`** / **`PacingGate`** → bounded queues → **`AudioCapture(..., speaker.is_playing)`** → transcription and reaction worker threads → **`capture.start()`**, stdout banners with timings, and graceful shutdown (sentinels + joins) on **`KeyboardInterrupt`**.
- Transcription thread: drains **`audio_queue`**, transcribes, applies **`passes_gate`**, uses **`_put_drop_oldest`** into **`reaction_queue`**, optionally logs density-gate rejects as JSONL when **`log_density_failures`** is true.
- Reaction thread: snapshots context, calls **`reactor.react(utterance, context_block)`** directly, receives **`(result, llm_latency_ms, discard_reason)`**, evaluates **`PacingGate`**, logs every path via **`HecklerLogger`**, uses **`_execute_spoken_reply`** so **`record_output()`** runs immediately before **`speaker.speak()`**, catches **`SpeakerError`** without crashing the thread, and pushes transcripts into **`ContextBuffer`** after handling.
- **CLI:** argparse exposes only **`--list-devices`** in addition to the default run path.

## Historical — pipeline packet narrative (superseded)

> **Not current.** Early T9 planning described **`_react_with_discard`**, wrapping **`reactor._client.messages.create`**, and disambiguating API vs score-gate failures by re-parsing raw bodies in the pipeline. Shipped code instead reads **`DiscardReason.LLM_ERROR`** vs **`SCORE_GATE`** (and parse failures surfaced as **`LLM_ERROR`**) **from `Reactor.react` alone**; there is **no** Anthropic **`messages.create`** wrapper in **`pipeline.py`**.

## Alternatives rejected

- **Pipeline-level raw-body re-parse:** Rejected once **`react`** returned the explicit discard-reason tuple; avoids mis-labeling failures.
- **Treating every `None` result from an older 2-value API as `SCORE_GATE`:** Rejected; would mis-label API/parse failures (historical concern only).

## Assumptions made (current)

- **`Reactor.react`** is the single call site that performs LiteLLM completion for a given utterance.
- Shutdown semantics (sentinels, bounded-queue drop-oldest) remain as implemented in **`pipeline.py`**.

## Items deferred

- **KeyboardInterrupt while workers are mid-queue:** same v1 tradeoff as originally noted—acceptable for foreground console use.
