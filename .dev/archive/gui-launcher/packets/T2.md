# Executor Packet — T2: CLI Adapter (revised after T5 amendment)

---

## §1 Task statement

Build a minimal PyQt6 GUI launcher for Heckler that replaces the blocking CLI `main()` loop with a Qt event loop, exposes persona hot-swap (runtime `Reactor` replacement between utterances) and mode switching (persona ↔ transcribe) in a single window with live transcript/reaction feeds and session controls. The GUI layer is the integration surface deferred by both the persona-system and transcription-engine plans.

**Non-goals:**

- Advanced GUI features (settings panels for VAD thresholds, LLM temperature sliders, session history browser, tray icon).
- Multi-window or multi-monitor support.
- Electron, web, or any non-PyQt6 frontend.
- Changes to the LLM, TTS, or transcription backends (Reactor, Speaker, Transcriber internals unchanged).
- Mobile or cross-platform packaging.
- CLI flag changes on the existing `heckler` entry point.

## Implementation guidance

### Rewritten `main()`

```python
def main(argv: Optional[list[str]] = None) -> None:
    parser = argparse.ArgumentParser(prog="heckler")
    parser.add_argument("--list-devices", action="store_true",
                        help="List audio devices via sounddevice and exit")
    parser.add_argument("--mode", choices=["persona", "transcribe"], default=None,
                        help="Pipeline mode: persona (full loop) or transcribe (capture + Whisper only)")
    parser.add_argument("--session-name", default=None,
                        help="Label for the transcription session (default: first 8 chars of session id)")
    parser.add_argument("--persona", type=str, default=None,
                        help="Persona name (maps to prompts/<name>/; default from HECKLER_PERSONA or 'heckler')")
    args = parser.parse_args(argv)

    if args.list_devices:
        print(sd.query_devices())
        return

    logging.basicConfig(level=logging.INFO)
    config = load_config()
    mode = args.mode if args.mode is not None else config.mode
    persona_name = args.persona or config.persona_name
    session_name = args.session_name or config.session_name

    from heckler.controller import ControllerCallbacks, PipelineController

    callbacks = ControllerCallbacks(
        on_transcript=lambda text: print(f"[TRANSCRIBE] {text}", flush=True),
        on_reaction=lambda result, spoken: (
            print(f"[HECKLER] {result.comment}", flush=True) if spoken else None
        ),
        on_status=lambda msg: print(f"[HECKLER] {msg}", flush=True),
        on_error=lambda err: print(f"[HECKLER] Error: {err}", flush=True),
    )

    controller = PipelineController(config, callbacks)

    try:
        controller.load_models(
            on_progress=lambda msg: print(f"[HECKLER] {msg}", flush=True),
            mode=mode,
        )
    except Exception as exc:
        print(f"[HECKLER] Error loading models: {exc}", flush=True)
        raise SystemExit(1) from exc

    try:
        controller.start(mode, persona_name=persona_name, session_name=session_name)
        try:
            while True:
                time.sleep(0.1)
        except KeyboardInterrupt:
            pass
    except PersonaNotFoundError as exc:
        print(f"[HECKLER] Error: {exc}", flush=True)
        raise SystemExit(1) from exc
    finally:
        controller.stop()
```

**Key points:**

- `--list-devices` stays before the controller (pure query, no pipeline needed).
- `load_models(mode=mode)` — transcribe mode skips Speaker; persona mode loads everything.
- `on_progress` callback prepends `[HECKLER] ` — e.g. controller emits `"Loading transcription model (large-v3 / CUDA)..."`, CLI prints `"[HECKLER] Loading transcription model (large-v3 / CUDA)..."`.
- `on_status` callback prepends `[HECKLER] ` — e.g. controller emits `"Mic open. Listening."`, CLI prints `"[HECKLER] Mic open. Listening."`.
- `on_transcript` prints `"[TRANSCRIBE] {text}"` — matches the legacy format from `_run_transcribe_worker`.
- `PersonaNotFoundError` may come from `controller.start()` (which calls `load_persona` internally). Catch it and print with `[HECKLER] Error:` prefix for parity with legacy behavior.
- The `from heckler.controller import ...` is a local import inside `main()` to avoid circular imports (controller.py imports from pipeline.py).

### Test retargeting strategy

**Category 1: `main()`-level tests that patch component constructors.**

These tests patch `heckler.pipeline.Transcriber`, `heckler.pipeline.Speaker`, etc. After the rewrite, `main()` delegates to `PipelineController`, which imports these from their source modules. The patches must be retargeted to the controller's namespace:

| Old patch target | New patch target |
|-----------------|-----------------|
| `heckler.pipeline.Transcriber` | `heckler.controller.Transcriber` |
| `heckler.pipeline.Speaker` | `heckler.controller.Speaker` |
| `heckler.pipeline.Reactor` | `heckler.controller.Reactor` |
| `heckler.pipeline.AudioCapture` | `heckler.controller.AudioCapture` |
| `heckler.pipeline.HecklerLogger` | `heckler.controller.HecklerLogger` |
| `heckler.pipeline.load_persona` | `heckler.controller.load_persona` |
| `heckler.pipeline.apply_persona_overrides` | `heckler.controller.apply_persona_overrides` |
| `heckler.pipeline.threading.Thread` | `heckler.controller.threading.Thread` |

`heckler.pipeline.load_config` stays — it's still called in `main()` before the controller.
`heckler.pipeline.time.sleep` stays — the `while True: time.sleep(0.1)` loop is still in `main()`.

**Category 2: `main()`-level tests that verify internal behavior (Reactor prompts, persona overrides).**

Tests like `test_main_passes_persona_prompts_to_reactor` and `test_main_reactor_receives_post_override_config` verify that Reactor receives specific arguments. After T2, Reactor construction happens inside the controller. These tests have two options:

a) **Retarget patches** to `heckler.controller.Reactor` and verify the constructor was called with expected args. This preserves the test's original intent.

b) **Replace with delegation test:** verify `controller.start(persona_name=...)` was called. This is simpler but tests less.

Prefer option (a) — retarget patches — to maintain coverage depth.

**Category 3: Worker-level tests (call `_run_*` directly).**

Tests like `test_reaction_worker_calls_reactor_react_directly`, `test_transcribe_worker_persists_chunks`, etc. These call worker functions directly, not through `main()`. They are **unchanged** — the functions still live in `pipeline.py` and the patches target `heckler.pipeline.*` correctly.

**Category 4: `test_main_transcribe_mode_does_not_load_speaker_or_reactor`.**

This test asserts that Speaker, Reactor, HecklerLogger, ContextBuffer, PacingGate, and load_persona are **never called** in transcribe mode. After T2, `main()` calls `controller.load_models(mode="transcribe")` which skips Speaker (T5 fix), then `controller.start("transcribe")` which doesn't construct persona-mode objects. Retarget the patches to `heckler.controller.*` and verify the same assertion holds. The test may also need `heckler.pipeline.load_config` patched (still in `main()`).
