# Executor Packet — T5: Controller Contract Alignment (Amendment)

**Amendment trigger:** T2 HALT report — three blocking findings against `heckler/controller.py` that prevented the CLI adapter from achieving behavioral parity with legacy `main()`.

---

## §1 Task statement

Build a minimal PyQt6 GUI launcher for Heckler that replaces the blocking CLI `main()` loop with a Qt event loop, exposes persona hot-swap (runtime `Reactor` replacement between utterances) and mode switching (persona ↔ transcribe) in a single window with live transcript/reaction feeds and session controls. The GUI layer is the integration surface deferred by both the persona-system and transcription-engine plans.

**Non-goals:**

- Advanced GUI features (settings panels for VAD thresholds, LLM temperature sliders, session history browser, tray icon).
- Multi-window or multi-monitor support.
- Electron, web, or any non-PyQt6 frontend.
- Changes to the LLM, TTS, or transcription backends (Reactor, Speaker, Transcriber internals unchanged).
- Mobile or cross-platform packaging.
- CLI flag changes on the existing `heckler` entry point.

## §2 Shared contracts

### Types / interfaces

**Signature change (T5 lands):**

```python
class PipelineController:
    def load_models(self, on_progress: Optional[Callable[[str], None]] = None, *,
                    mode: Optional[str] = None) -> None: ...
    # mode="transcribe" → skip Speaker construction
    # mode=None (default) → load all models (GUI path for runtime mode switching)
```

The `mode` parameter is keyword-only and optional. Existing callers (T3/GUI calling `load_models()` or `load_models(on_progress=...)` without `mode`) are unaffected — they get all models loaded.

**Status-string contract (T5 lands):**

Controller messages via `on_progress` and `callbacks.on_status` carry semantic content **without** the `[HECKLER]` prefix. Consumers add presentation formatting.

**`on_progress` strings (from `load_models`):**

| Message | When |
|---------|------|
| `Loading transcription model ({size} / CUDA)...` | Before Transcriber construction |
| `Transcription ready. ({elapsed:.1f}s)` | After Transcriber construction |
| `Loading TTS model (Kokoro / {voice})...` | Before Speaker construction (skipped when `mode="transcribe"`) |
| `TTS ready. ({elapsed:.1f}s)` | After Speaker construction |

**`on_status` strings (from `start` / `stop`):**

| Message | When |
|---------|------|
| `Mic open. Listening.` | After persona-mode startup |
| `Transcribe mode — mic open. Ctrl+C to stop.` | After transcribe-mode startup |
| `Transcribe session ended (id={id}, markdown={path})` | After transcribe-mode session close in `stop()` |

**Retired:** The `Running in {mode} mode.` line emitted by v1.0 controller is removed.

## Implementation guidance

### Change 1: Mode-aware `load_models()`

Current code (controller.py lines 106–119):

```python
def load_models(self, on_progress: Optional[Callable[[str], None]] = None) -> None:
    def _prog(msg: str) -> None:
        if on_progress is not None:
            on_progress(msg)

    _prog(f"Loading transcription model ({self._config.whisper_model_size})...")
    self._transcriber = Transcriber(self._config)
    _prog("Transcription model ready.")

    _prog(f"Loading TTS model ({self._config.kokoro_voice})...")
    self._speaker = Speaker(self._config)
    _prog("TTS model ready.")
```

Target:

```python
def load_models(
    self,
    on_progress: Optional[Callable[[str], None]] = None,
    *,
    mode: Optional[str] = None,
) -> None:
    import time as _time

    def _prog(msg: str) -> None:
        if on_progress is not None:
            on_progress(msg)

    _prog(f"Loading transcription model ({self._config.whisper_model_size} / CUDA)...")
    t0 = _time.perf_counter()
    self._transcriber = Transcriber(self._config)
    _prog(f"Transcription ready. ({_time.perf_counter() - t0:.1f}s)")

    if mode != "transcribe":
        _prog(f"Loading TTS model (Kokoro / {self._config.kokoro_voice})...")
        t1 = _time.perf_counter()
        self._speaker = Speaker(self._config)
        _prog(f"TTS ready. ({_time.perf_counter() - t1:.1f}s)")
```

Note: `time` is already imported at module top-level; the local `import time as _time` in the example is just for clarity — use the existing module-level import.

### Test updates

1. **`test_load_models_transcribe_skips_speaker`**: Call `ctrl.load_models(mode="transcribe")`, assert `ctrl._speaker is None`, assert `ctrl._transcriber is not None`.

2. **`test_load_models_default_loads_all`**: Call `ctrl.load_models()` (no mode), assert both `ctrl._transcriber` and `ctrl._speaker` are not None.

3. **`test_on_status_persona_mic_open`**: Start persona mode, check `on_status` was called with `"Mic open. Listening."`.

4. **`test_on_status_transcribe_mic_open`**: Start transcribe mode, check `on_status` was called with a string containing `"Transcribe mode"` and `"mic open"`.

5. **`test_on_progress_includes_cuda_and_timing`**: Call `load_models` with a mock `on_progress`, assert one message contains `"/ CUDA"` and one contains a timing suffix matching `r"\(\d+\.\d+s\)"`.

6. **Update `test_controller_on_status_called_on_start_and_stop`**: The existing test checks for `"Running"` in status calls — this must be updated since that string is retired. Check for `"Mic open"` or `"Transcribe mode"` instead.
