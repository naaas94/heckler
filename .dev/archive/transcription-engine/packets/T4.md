## §1 Task statement

Add a **transcribe-only mode** to heckler: a standalone pipeline path that uses `AudioCapture` + `Transcriber` (Whisper) without loading the Reactor (LLM), Speaker (Kokoro TTS), or any gates (density, score, pacing). Audio input is continuously transcribed and persisted to SQLite (session + chunks) with optional incremental markdown export. A new `--mode transcribe` CLI flag activates the mode (amending the prior `--list-devices`-only CLI contract). VAD timing defaults are overridden for longer-form speech in transcribe mode. Session lifecycle (start/stop/naming) is managed at the pipeline level.

**Non-goals:**

- PyQt6 GUI integration (separate follow-on plan).
- Speaker diarization / `pyannote.audio` integration.
- Raw audio chunk archival to disk.
- Streaming/partial transcription (Whisper streaming); chunk-based only.
- Changes to `HeckleEvent` schema, `event_store.py` DDL, or `SCHEMA_VERSION`.
- Intentional removal or disabling of persona-mode features. **Co-landing:** other plans may touch the same files (`pipeline.py`, `config.py`, `reactor.py`); the behavioral contract is **regression-tested persona behavior** (`tests/test_pipeline.py` and related), not a freeze on line-level diffs (audit **F3**).
- Modifications to `Transcriber.run` (legacy/test-only method).

## Filtered §5.4 — Hidden couplings (T4)

1. `(shared SQLite file for events + transcripts | §2 Types / config.sqlite_database_path | if both init_schema and init_transcript_schema run in the same main() call, WAL lock ordering or busy-timeout contention could cause startup failure | T1, T4)` — **suspected.** Disproven by: WAL allows concurrent readers/writers; both init paths use `CREATE TABLE IF NOT EXISTS`; no cross-table FKs. ## Implementation guidance

### 1. Import changes

Add at the top of `pipeline.py` (conditional or unconditional):

```python
import dataclasses
from pathlib import Path
from heckler.transcript_store import (
    init_transcript_schema,
    create_session,
    close_session,
    insert_chunk,
    export_session_markdown,
)
from heckler.event_store import open_store
```

Note: The imports of `Reactor`, `Speaker`, `ContextBuffer`, `PacingGate`, `HecklerLogger`, `passes_gate`, `SpeakerError` etc. remain at module level (they don't load models at import time — model loading happens in `__init__`). The key optimization is skipping their *construction* in transcribe mode.

### 2. `_run_transcribe_worker` function

```python
def _run_transcribe_worker(
    *,
    config: HecklerConfig,
    audio_queue: queue.Queue,
    transcriber: Transcriber,
    transcript_conn: sqlite3.Connection,
    session_id: str,
    transcript_lock: threading.Lock,
) -> None:
```

Loop structure:
- Drain `audio_queue` (same sentinel pattern as `_run_transcription_worker`)
- On each `AudioChunk`: call `transcriber.transcribe(chunk).strip()`
- Skip empty transcripts
- Increment a local `sequence_num` counter (starts at 1)
- Call `insert_chunk(transcript_conn, session_id=session_id, chunk_text=text, timestamp_iso=_now_iso(), duration_s=chunk.audio.shape[0] / config.sample_rate, sequence_num=sequence_num)` under `transcript_lock`
- Print `[TRANSCRIBE] {text}` to stdout for live feedback
- On sentinel `None`: break

### 3. `main` modifications

**Argparse additions** (after `--list-devices`):

```python
parser.add_argument(
    "--mode",
    choices=["persona", "transcribe"],
    default=None,  # None means "use config.mode"
    help="Pipeline mode: persona (default, full heckler loop) or transcribe (transcription only)",
)
parser.add_argument(
    "--session-name",
    default=None,
    help="Name for the transcription session (default: auto-generated)",
)
```

**Mode dispatch** (after `config = load_config()` and before model loading):

```python
mode = args.mode or config.mode

if mode == "transcribe":
    # Transcribe-only path
    # ... (see below)
else:
    # Existing persona-mode path (unchanged)
    # ...
```

**Transcribe mode path:**

1. Load only `Transcriber` (skip Speaker, Reactor, ContextBuffer, PacingGate, HecklerLogger)
2. Open transcript DB connection: `transcript_conn = open_store(Path(config.sqlite_database_path))` then `init_transcript_schema(transcript_conn)`
3. Create session: generate `session_id = str(uuid.uuid4())`, determine `session_name = args.session_name or config.session_name or session_id[:8]`
4. `create_session(transcript_conn, session_id=session_id, name=session_name)`
5. Apply VAD overrides for transcribe mode:

```python
effective_config = dataclasses.replace(
    config,
    max_speech_duration_s=config.transcribe_max_speech_duration_s,
    silence_duration_ms=config.transcribe_silence_duration_ms,
    min_speech_duration_ms=config.transcribe_min_speech_duration_ms,
)
```

6. Create `audio_queue`, `is_playing = threading.Event()` (permanently clear)
7. Create `AudioCapture(effective_config, audio_queue, is_playing)`
8. Create `transcript_lock = threading.Lock()`
9. Start transcribe worker thread with `_run_transcribe_worker`
10. `capture.start()`, print banner, wait loop
11. On `KeyboardInterrupt` / shutdown:
    - `capture.stop()`
    - `_put_shutdown_sentinel(audio_queue)`
    - Join transcribe thread
    - `close_session(transcript_conn, session_id)`
    - `export_session_markdown(transcript_conn, session_id, Path(config.transcripts_dir) / f"{session_name}.md")`
    - Print session summary

### 4. Existing persona-mode path

The existing code in `main` (from `heckler_logger = HecklerLogger(config)` through shutdown) moves into the `else` branch. No functional changes to persona mode.

### Reference: `AudioCapture.__init__` signature

```python
class AudioCapture:
    def __init__(
        self,
        config: HecklerConfig,
        out_queue: queue.Queue,
        is_playing: threading.Event,
    ) -> None:
```

The `is_playing` parameter is typed as `threading.Event` — any `threading.Event()` instance works. AudioCapture only calls `is_playing.is_set()` in `_emit_audio_segment`. A never-set Event means the mic gate check always passes (audio always enqueued).
