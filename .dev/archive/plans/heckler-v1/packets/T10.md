## §1 Task Statement

Build HECKLER, a local reactive audio commentary loop that captures microphone input continuously, segments on silence boundaries via Silero VAD, transcribes via local faster-whisper, generates snarky commentary via Claude Haiku, applies quality and pacing gates, synthesizes speech via Kokoro TTS, and plays back through system audio. Every pipeline event is logged to JSONL regardless of outcome. The system runs as a local Python process on Windows (RTX 3060 / Ryzen 5 / 64 GB RAM) with a soft latency target of 2.5 seconds end-to-end.

**Non-goals:**

- No conversational ability — HECKLER does not respond to user intent directed at it
- No GUI or web interface — console-only with JSONL logging
- No multi-language support — English only for v1
- No cloud TTS or cloud STT — all inference is local except the LLM call
- No persistent state across sessions — no DB, no session memory beyond the rolling context buffer
- No Windows service / daemon mode — runs as a foreground console process
- No score threshold auto-calibration — manual tuning from JSONL logs

## Definition of Done — Five Deliverables

### 1. Fix setuptools package discovery in `pyproject.toml`

Append this section to `pyproject.toml`:

```toml
[tool.setuptools.packages.find]
include = ["heckler*"]
```

This prevents `prompts/`, `tests/`, `logs/`, and any other top-level directory from being discovered as a package.

**Verification:** `pip install -e .` must succeed without "multiple top-level packages" error.

### 2. Widen `reactor.react()` return type

**Current signature (T7 as-shipped):**

```python
def react(self, utterance: Utterance, context_block: str) -> tuple[Optional[ReactorResult], float]:
```

**New signature:**

```python
def react(self, utterance: Utterance, context_block: str) -> tuple[Optional[ReactorResult], float, Optional[DiscardReason]]:
```

**Semantics of the third element:**

| Condition | Return |
|---|---|
| Success (result parsed, score passes) | `(result, latency_ms, None)` |
| API call fails (exception caught) | `(None, latency_ms, DiscardReason.LLM_ERROR)` |
| Response not parseable JSON | `(None, latency_ms, DiscardReason.LLM_ERROR)` |
| Score below threshold | `(None, latency_ms, DiscardReason.SCORE_GATE)` |

**Implementation in reactor.py** — modify the three return-None paths:

```python
# Path 1: API exception (currently line ~79)
# Before: return None, elapsed_ms
# After:
return None, elapsed_ms, DiscardReason.LLM_ERROR

# Path 2: _parse_response returns None (currently line ~85)
# Before: return None, elapsed_ms
# After:
return None, elapsed_ms, DiscardReason.LLM_ERROR

# Path 3: score < threshold (currently line ~87)
# Before: return None, elapsed_ms
# After:
return None, elapsed_ms, DiscardReason.SCORE_GATE

# Path 4: success (currently line ~88)
# Before: return parsed, elapsed_ms
# After:
return parsed, elapsed_ms, None
```

Add `DiscardReason` to the imports from `heckler.models`.

**Do not change** `_parse_response`, `_format_examples_block`, or `_extract_text_content`. The `_extract_text_content` function stays in reactor.py (other code may use it); only the pipeline import of it is removed.

### 3. Simplify `pipeline.py` — remove monkey-patching

**Remove entirely:**
- `_install_reactor_discard_tracking()` function
- `_react_with_discard()` function
- The import of `_extract_text_content` from `heckler.reactor`

**In the reaction worker** (the function that drains `reaction_queue`), replace the call:

```python
result, llm_latency_ms, none_reason = _react_with_discard(reactor, utterance, context_block)
```

with:

```python
result, llm_latency_ms, discard_reason = reactor.react(utterance, context_block)
```

Then use `discard_reason` directly wherever `none_reason` was used to construct `HeckleEvent.discard_reason`. The downstream logic (pacing gate, speaker, logger) is unchanged — only the source of the discard reason changes.

### 4. Update tests

**`tests/test_reactor.py`:** All existing test cases must be updated to expect a 3-tuple return from `react()`:
- Valid response → `(ReactorResult, latency, None)`
- Leading-text JSON (regex fallback) → `(ReactorResult, latency, None)`
- Invalid JSON → `(None, latency, DiscardReason.LLM_ERROR)`
- Score below threshold → `(None, latency, DiscardReason.SCORE_GATE)`
- Score at exactly threshold → `(ReactorResult, latency, None)` (passes — `<` comparison)
- API exception → `(None, latency, DiscardReason.LLM_ERROR)`

**`tests/test_pipeline.py`:** Remove or update any tests that assert on `_react_with_discard`, `_install_reactor_discard_tracking`, or `_extract_text_content` import from reactor. Reaction-worker tests should assert that `reactor.react()` is called directly (no wrapping).
