## §1. Task statement (verbatim)

Heckler's GUI and CLI fail to propagate locale into the Whisper and Kokoro heavy models when the operator selects a persona with a non-English locale (e.g. `heckler_arg` with `locale = "es"`). This plan delivers: a reload-predicate API based on `(whisper_language, kokoro_lang_code)` signature comparison, a unified `_apply_persona_and_speech` orchestration entry point, a reload policy (auto on Start, ask while running), and CLI parity.

**Non-goals (v1):** Speaker-only reload on voice-only change; persisting locale override; LLM locale injection; locale in Transcribe mode; new locales beyond `en/en-us/en-gb/es`; in-place model swap; GUI theme changes; QSettings "don't ask again".

### `loaded_speech_stack`

```python
def loaded_speech_stack(self) -> tuple[str, str] | None:
    if self._transcriber is None:
        return None
    from heckler.locale import speech_stack_signature
    return speech_stack_signature(self._transcriber._config)
```

### `target_speech_config`

```python
def target_speech_config(
    self,
    *,
    persona_name: Optional[str],
    locale_override: Optional[str] = None,
) -> HecklerConfig:
    from dataclasses import replace
    base = self._config
    if persona_name:
        prompts_root = Path(__file__).resolve().parent.parent / "prompts"
        persona = load_persona(prompts_root / persona_name)
        cfg = apply_persona_overrides(base, persona)
    else:
        cfg = apply_resolved_locale(base)
    if locale_override:  # None and "" both falsy — sentinel rule satisfied
        cfg = apply_resolved_locale(replace(cfg, locale=locale_override))
    return cfg
```

### `heavy_models_need_reload`

```python
def heavy_models_need_reload(
    self,
    *,
    persona_name: Optional[str],
    locale_override: Optional[str] = None,
) -> bool:
    from heckler.locale import speech_stack_signature
    target = self.target_speech_config(persona_name=persona_name, locale_override=locale_override)
    loaded = self.loaded_speech_stack()
    return loaded is None or speech_stack_signature(target) != loaded
```

### `ensure_heavy_models`

```python
def ensure_heavy_models(
    self,
    *,
    persona_name: Optional[str],
    locale_override: Optional[str] = None,
    on_progress: Optional[Callable[[str], None]] = None,
    mode: str = "persona",
) -> bool:
    if self.heavy_models_need_reload(persona_name=persona_name, locale_override=locale_override):
        self.load_models(on_progress=on_progress, mode=mode,
                         persona_name=persona_name, locale_override=locale_override)
        return True
    return False
```
