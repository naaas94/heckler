# T10 — Heckler LLM config / env schema (LiteLLM provider switch)

## Chosen approach

- **`HecklerConfig.llm_model`** defaults to **`openai/gpt-4o-mini`** (LiteLLM model id). Operators override via **`HECKLER_LLM_MODEL`** when non-empty (after strip); whitespace-only falls back to the default.
- **API keys** use **`os.getenv(..., "")`** so missing variables yield empty strings—no **`KeyError`** at config load. **`ANTHROPIC_API_KEY`** maps to **`anthropic_api_key`**, **`OPENAI_API_KEY`** maps to **`openai_api_key`**.
- **`OLLAMA_API_BASE`** maps to **`ollama_api_base`** (v1 frozen name per shared contract). Empty default means unset; T2’s LiteLLM wiring decides how empty vs non-empty affects routing.
- **`litellm`** is added as a runtime dependency for upcoming **`litellm.completion`** use in T2.

## Alternatives rejected

- **Require at least one provider key at `load_config`:** Rejected—contract mandates optional keys and getenv semantics; failures belong at call time (T2) with **`DiscardReason.LLM_ERROR`**, not import/config time.
- **Rename `OLLAMA_API_BASE` / `ollama_api_base` for v1:** Rejected—§2 freezes the env name; renaming would break contract and downstream docs.

## Assumptions made

- **`openai/gpt-4o-mini`** remains a valid LiteLLM route for the repo’s Python range once T2 calls the API (validated in integration/T4 as needed).
- **`anthropic` PyPI package** remains listed until **T2** removes **`from anthropic import Anthropic`** from **`heckler/reactor.py`**; dropping it in T1 would break **`import heckler.reactor`** and pytest collection for **`tests/test_reactor.py`** without touching reactor (out of T1 scope).

## Items deferred

- **Remove `anthropic` from `pyproject.toml`:** Deferred to **T2** when the reactor no longer imports the Anthropic SDK.
